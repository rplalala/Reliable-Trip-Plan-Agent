# Triage labels

The triage skill uses five canonical roles. In this local Markdown tracker, record the corresponding value in an issue's `Status:` line.

| Triage role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs maintainer review |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified for agent work |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

The wayfinding workflow also uses `claimed` and `resolved` for work in progress and completed tickets.
